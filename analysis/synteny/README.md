# Synteny analysis: within-chromosome gene-order scrambling (mesosynteny)

Tests whether within-chromosome gene order is scrambled faster, relative to
sequence divergence, in the clades that lost the centromeric proteins CENP-A
(Umbelopsidales + Mucorales) and CENP-C (Mucorales) than in Mortierellales,
which retain both.

- Report: [`synteny_report.html`](synteny_report.html) (rendered from
  [`synteny_report.Rmd`](synteny_report.Rmd))
- Decision log: [`DECISIONS.md`](DECISIONS.md)
- Literature search log: [`LITERATURE.md`](LITERATURE.md)

## Approach in brief

1. Anchors: one-to-one orthologues between every pair of genomes within an
   order (OrthoFinder 2.5.4 pairwise orthologues), placed on the assemblies
   with the per-genome gene position tables.
2. Gene-order indices per genome pair at three scales, normalised to
   1 = conserved and 0 = random order within chromosomes:
   macro (do neighbours stay on the same chromosome), meso (strand
   randomisation, correlation and Kendall's tau indices of Plessy et al.
   2024 / GenomicBreaks), micro (gene order conservation, GOC; Rocha 2003).
3. Decay of each index with sequence divergence (patristic distance on the
   CDS ML tree), `I(d) = c * exp(-(lambda * d)^beta)`, with clade-specific
   rates `lambda`.
4. Clade rates compared on random sets of phylogenetically independent genome
   pairs (1,000 draws; one-sided Wilcoxon tests).

## Running

```bash
bash analysis/synteny/run_all.sh
```

Set `SKIP_DOWNLOAD=1` to reuse downloaded data. Indices for the 1,158 genome
pairs take roughly 15-20 minutes on 10 cores in an ordinary terminal (much
longer when the process runs at background priority). Delete
`results/cache/pair_indices/` to force recomputation.

R packages: tidyverse, ape, igraph, patchwork, rmarkdown, knitr.

## Inputs (downloaded into `data/`)

- `data/orthofinder/results/Orthologues/...` pairwise orthologue tables
  (1,158 files) and `Orthogroups/Orthogroups.tsv`
- `data/genomes/<genome>/<genome>_genePosTbl.tsv`, `<genome>_IDtbl.tsv`
- `data/phylogeny/sco_cds_withOutgroups_b500.treefile` (ML, CDS),
  `sco_cds_b500.date.nwk` (dated), OrthoFinder species tree
- `data/metadata/*` genome metadata
